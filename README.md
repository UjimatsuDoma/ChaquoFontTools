# ChaquoFontTools

网上基本找不到适用JVM的字体文件处理库（Aspose收费），少数几个没有我其他项目需要的一些功能（如可变字体转静态字体），遂有了这个库。
This library is created out of spite during maintenance of my other projects: there's almost no versatile font processor written in JVM-compatible languages, and FOSS.

路线图：字体转换功能；字体信息读取
Roadmap: Font conversion; Font metadata query
